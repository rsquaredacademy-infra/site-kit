Long page fixture

This demo page is deliberately long. Scroll down past half of the document height with variant B active and the slim sign-up bar slides up from the bottom of the viewport. With variant A it never appears.

The bar is not a modal: the page stays usable, focus is never moved, and Escape dismisses it only while focus is inside the bar. Closing it stores a 30-day dismissal; a successful sign-up on this origin stops it from ever showing again.
